# 0004. 로그인 없이 일반 기능을 쓰고, 원본 자료 변경은 관리자만 즉시 반영한다

- 상태: 대체됨(0016)
- 날짜: 2026-09-30
- 관련: [`../specs/api.md`](../specs/api.md#2-인증과-쓰기-보호), [`../user-guide.md`](../user-guide.md#2-역할과-승인)

## 배경

1.2.0은 관리자·담당자·열람자 계정과 변경 승인 절차를 두었지만, 시연·팀 사용에서 로그인과 승인 대기가 기본 기능 사용을 막았습니다. 동시에 문서·운항 원본이 아무나 바뀌면 근거 신뢰성이 무너집니다.

## 결정

- 일반 사용자는 로그인 없이 공개 문서 조회·질문, 운항 조회·분석·계산, 자기 보고서 초안 작성·검토 요청을 한다. 작업공간은 무작위 `haedap_guest` 쿠키로 구분한다(인증 아님).
- 로그인은 관리자만. 기본 관리자는 `admin / 1234`로 고정한다(캡스톤 시연용 요청 사항).
- 문서·선박·운항 변경은 관리자만 가능하고 승인 대기 없이 즉시 반영한다. 서버에서 역할을 검사한다.
- 보고서는 관리자 작성분도 검토 요청 → 승인을 거친다.
- 기존 담당자·열람자 계정 레코드는 보존하되 로그인은 막는다.

## 검토한 대안

| 대안 | 채택하지 않은 이유 |
|---|---|
| 모든 사용자 로그인 + 변경 승인 유지(1.2.0) | 시연·팀 사용에서 진입 장벽이 큼 |
| 완전 공개(쓰기 포함) | 근거 문서·운항 원본의 신뢰성 훼손 |

## 결과

- 좋아지는 점: 바로 사용 가능, 원본 자료 보호, 서버 측 권한 검사 유지.
- 감수하는 점: 고정 비밀번호와 쿠키 기반 구분은 **인터넷 공개 배포에 부적합**. 같은 브라우저 프로필을 쓰면 같은 작업공간.
- 지켜야 할 규칙: 접속 범위는 로컬/LAN으로 한정(ADR 0002, `network.mjs`). 실제 배포 전에는 이 ADR을 대체하는 인증 결정을 새로 해야 함.
