## 1. 배경과 목표

게스트에게 업무 자료를 공개하고 공용 관리자 비밀번호에 의존하던 구조를 개인 계정과 서버 권한 검사로 전환한다. 사용자의 요청에 따라 국내 개인정보 보호 기준과 IMO 원문을 확인하고, 법적 요구와 프로젝트가 선택한 정책을 구분한다.

## 2. 범위

- 포함: 선원·관리자 로그인, 관리자에 의한 개인 계정 발급·회수, 초기 비밀번호 변경, 익명 업무 API 차단, 세션 만료·회수, 운영 안내, 실제 로컬 Ollama 호출, CI 검증 및 #14 후속 병합.
- 제외: 선박 조종·안전 필수 시스템, 공개 회원가입, 법적 적합성 인증, 공식 CII 산정, 팀원의 #15~#17 병합.

## 6. 열린 질문

실선 적용 시 기국·선사·접속망·개인정보 보유 규모는 아직 제공되지 않았다. 현재는 국내 소규모 내부 업무지원 앱으로 설계하며, MFA/VPN, 로그 보존·점검 및 선사 안전관리체계 적용은 배포 환경에 맞춰 별도 확인한다.
