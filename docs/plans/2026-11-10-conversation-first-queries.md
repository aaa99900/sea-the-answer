## 배경과 목표

팀 main의 PR #24·#25 구현을 바탕으로, 일반 사용자가 도구 선택이나 조건 양식을 먼저 조작하지 않고 질문과 짧은 답변으로 기존 조회를 완료하게 한다. 관리자 자료 등록·명시적인 실제 선박 매핑은 별도 준비 작업으로 유지한다.

## 범위

- 기존 운항·MRV·선택 문서·항구 경로 재사용. 필요한 조건을 한 번에 하나씩 묻고, 등록 선박명/IMO·기간·문서명으로 답하면 원래 작업을 이어간다.
- AIS 자료 보유·등록·수집 현황 질문을 일반 문서 검색과 구분하고, 실제 연결된 catalog summary로 건수·출처·시점·노후화와 선택 선박 포함 여부를 답한다.
- 화면에서 자동으로 고른 첫 선박·고정 기본 날짜를 사용자 지정 조건으로 보내지 않는다. 직접 지정하거나 대화에서 확인한 선박은 후속 질문에 사용한다.
- 대화 세션·언어 선택·인용·권한·조회 한도·계산 불가 사유를 보존한다. 양식은 선택적인 보조 입력으로 남긴다.
- 제외: 운영 서버 변경/실제 선박 임의 등록·매핑, 새 모델 설치, 공식 CII·입항 승인, 자유 SQL/자동 쓰기, 원격 push/PR.

## 위험과 대응

짧은 새 질문을 이전 작업으로 잘못 연결하지 않도록 등록 명칭·날짜·동의 표현으로만 이루어진 응답을 제한적으로 받는다. 다른 소유자/대화·변경된 선박·문서 권한은 재확인하고, 모르는 명칭이나 부정 표현을 임의의 선택/동의로 바꾸지 않는다. LLM의 자율 해석 성능을 검증한 것으로 기록하지 않는다.
