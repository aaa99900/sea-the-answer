# 선원·관리자 인증

- 상태: 구현됨
- 작성: 2026-10-21
- 관련: [API](api.md), [ADR 0016](../adr/0016-crew-admin-authentication.md)

## 목적과 범위

개인별 계정, 최소 권한, 세션 회수 및 비밀번호 변경을 FastAPI에서 강제한다. 법령 근거와 운영 적용 범위는 ADR에만 기록한다.

## 인터페이스

- `GET /api/health`: 익명에게도 연결 확인·CSRF 토큰 제공. `authenticated`는 활성 계정 세션 존재 여부, `publicAccess=false`. 익명에게 업무 자료나 문서 개수를 공개하지 않는다.
- `POST /api/auth/login`: `{username,password}`. 활성 `admin/operator/viewer` 계정 모두 허용. 역할 선택 입력으로 권한을 부여하지 않는다. 반환값 `{user}`에는 `password`가 없고 `must_change_password`가 포함된다.
- `POST /api/auth/password`: `{currentPassword,newPassword}`. 로그인한 본인만 변경한다. 현재 비밀번호 재확인, 새 비밀번호 검증, 계정 버전 증가 후 현재 브라우저 세션을 재발급한다. 다른 세션은 무효.
- `POST /api/auth/logout`: 현재 세션 종료. 이후 업무 접근 401.
- `POST /api/users`: 관리자만 개인 계정 생성·권한 변경·비활성화·비밀번호 초기화. 새 계정과 초기화된 계정은 `must_change_password=true`. 본인 또는 마지막 활성 관리자의 관리자 권한 제거를 금지한다.
- 공개 회원가입과 웹 초기 관리자 설정 API는 제공하지 않는다.

## 규칙

1. 인증 전에는 health와 로그인·로그아웃만 허용한다. 나머지 앱 API는 `401 AUTH_REQUIRED`. 별도 해사 데이터 API의 서버 Bearer 인증 경계는 유지한다.
2. 초기 비밀번호 변경이 필요한 계정은 health·비밀번호 변경·로그아웃 외 업무 요청을 `403 PASSWORD_CHANGE_REQUIRED`로 거절한다.
3. 선원은 허용된 문서·운항 정보 조회, 질문·계산, 자기 보고서 작성·검토 요청이 가능하다. 원본 문서·운항 수정, 승인, 사용자·로그·백업 관리는 관리자만 가능하다. 열람 계정은 보고서를 저장할 수 없다.
4. 비밀번호는 12~128자이고 공백 제거·바이트 절단 없이 해시한다. 영문·숫자·기호를 강제 조합하는 법정 기준이라고 주장하지 않는다. 아이디와 같거나 알려진 기본 비밀번호는 거절한다. scrypt + 개별 salt를 유지한다.
5. 세션은 HttpOnly·SameSite=Strict. HTTPS 운영 설정에서는 Secure를 사용한다. 30분 유휴 또는 12시간 절대 만료. 계정 버전·활성·역할을 요청마다 확인한다.
6. 로그인·비밀번호 변경 시도는 계정 단위 5회/15분, 요청 출처 단위 100회/15분으로 제한한다. 성공하면 해당 계정의 횟수를 초기화하므로 계정 제한은 연속 실패에 적용된다. 출처 제한에는 성공한 시도도 포함한다. 단일 프로세스 메모리 정책이며 재시작 시 초기화된다. 운영 외부망 보호는 별도 VPN/인증·접근 제어와 함께 적용한다.
7. 첫 관리자만 서버 운영자가 명시한 초기 설정으로 만든다. 내장 공용 비밀번호는 없다. 기존 계정은 마이그레이션 후 비밀번호를 변경해야 한다. 기존 게스트 자료를 다른 계정에 자동 귀속시키지 않는다.
8. 권한 변경 내역에는 행위자·대상 계정 ID와 변경 전후 역할·활성 상태를 남기며 비밀번호·해시·세션 값은 기록하지 않는다.

## 수용 기준

- 익명 직접 API 호출·직접 페이지 이동으로 업무 자료에 접근할 수 없다.
- 선원이 관리자 API를 호출하면 403, 다른 선원의 개인 자료는 조회·수정할 수 없다.
- 비활성화·역할 변경·비밀번호 초기화·로그아웃·만료 후 이전 세션은 사용할 수 없다.
- 초기 비밀번호 변경 전 업무 데이터가 로드되지 않는다.
- 잘못된 암호·중복 아이디·버전 충돌·마지막 관리자 변경을 검증한다.
- 실제 PostgreSQL 및 브라우저 흐름으로 검증하고 실행 환경 제약은 결과에 명시한다.
