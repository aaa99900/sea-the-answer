# OpenSearch 키워드 검색

- 상태: 구현됨
- 날짜: 2026-11-11
- 관련: [ADR 0023](../adr/0023-opensearch-lexical-index.md)

## 분석과 검색

OpenSearch 3.9.0/Nori가 문서와 질의를 분석한다. title/reference/heading/text를 동일 가중치로 하나의 필드에 결합한다. NFKC·소문자 정규화, Nori mixed 분해, 조사/어미 제거와 해사 사용자 사전을 적용한다. 부정·수치·단위는 남긴다. 동의어는 원 질의에만 한 번 확장한다. 분석/사전 계약 해시가 바뀌면 새 물리 색인을 생성하고 재색인·검증 후 alias를 원자적으로 전환한다.

Nori가 나누는 소수·조항 번호는 별도 keyword 식별자 필드에도 보존한다. VX/VA의 부정 표현은 유지하고 조사·어미와 XSV/VCP를 제외한다. 사용자 사전 경계에서 일반 품사로 오인된 `이`·`의`도 불용어로 제외한다. `경우`는 유지한다. 별칭은 원 질의의 연속 토큰 구에만 적용하고 확장 토큰을 다시 확장하지 않는다. 영문 stemming은 하지 않는다. Lucene 기본 BM25 점수와 chunk_id 오름차순 동점을 사용하므로 이전 Python 점수·동점 순서와 완전히 일치하지 않는다. RRF의 동점 규칙은 유지한다.

확장 뒤 질의 토큰은 중복 제거 후 최대 128개다. 분석기 설정·사전은 fingerprint에 포함하고, 코드로 정의한 정규화/식별자 규칙을 바꾸면 계약 버전도 올린다. 문서 토큰·질의·권한·검색 결과의 Python 캐시는 없다. 작은 고정 공개 별칭의 Nori 분석 결과만 프로세스에서 재사용한다.

문서 개정·검색 입력 해시·분석 계약과 묶인 완료 receipt는 같은 물리 색인에 저장한다. 저장소 교체는 receipt도 제거한다. 검색은 문서별 receipt를 일괄 조회하고 준비된 PG 허용 청크의 정확한 record ID로 Top-K 전에 제한한다. BM25 통계는 전체 색인 기준이다. 최종 본문·메타데이터는 PG 원본에서 반환하고 다시 권한·내용을 확인한다. 전체 후보 PG 읽기는 벡터 내용 검증 때문에 남지만 최종 재조회는 반환 ID로 제한한다.

## 동기화

새 lexical 작업 테이블은 문서별 generation·claim·시도·오류·재시도 시간을 보존한다. 원본 변경 트리거는 커밋 전 같은 트랜잭션에서 enqueue한다. 삭제 tombstone 때문에 문서 FK는 두지 않는다. 세션 advisory lock과 최종 generation 확인으로 worker/수동 작업을 직렬화한다. 청크는 내용별 불변 ID로 쓰고 refresh 이후 검증한 문서에만 완료 receipt를 발행한다. 부분 실행은 전체 완료로 표시하지 않는다. 오래된 작업의 receipt는 최신 snapshot과 일치하지 않는다. 작업 실패는 원문 저장을 취소하지 않는다.

## 실패·진단

두 엔진 성공은 hybrid, 한 엔진만 성공하면 해당 엔진, 둘 다 불가하면 SEARCH_UNAVAILABLE(503)이다. 빈 일치 결과는 엔진 장애가 아니다. 일부 문서만 준비된 경우 각 엔진의 참여 범위·제외 사유를 CLI와 안전한 로그에서 표시한다. 청크가 손상되면 명시적 검증/복구 CLI를 사용한다. 검색은 색인이나 복구를 실행하지 않는다. 원문·접속 비밀값을 오류 로그에 포함하지 않는다.

검색은 문서 receipt와 반환 record를 검증하며, 반환되지 않은 record의 임의 삭제까지 전수 검사하지 않는다. 저장소 장애·수동 변경 뒤에는 `lexical_index.py verify`로 검사한다. `verify --apply`는 복구를 enqueue하고, `index --apply`는 같은 worker 경로로 직접 처리한다. 전체 PG 후보 읽기·해시·허용 ID 전달 비용과 별도 엔진 메모리 비용은 남는다. 두 엔진의 준비 범위가 다르면 양쪽에 참여한 문서가 RRF에서 유리할 수 있으며 정확도 개선을 보장하지 않는다.

## 검증 계약

권한/개정/상태/kind/선택 문서 사전 제한, 최종 PG 재검증, 중복·동시 변경·롤백·장애·재시작·부분 실행·저장소 교체, Nori 한영/부정/조항 분석과 실제 OpenSearch 검색을 격리 자료로 검증한다. 모의 테스트를 실제 엔진 검증으로 기록하지 않는다.
